# Command Centre visual verification

Reference: [Figma 8:651](https://www.figma.com/design/rqWc0iFUFSTdudXuO4Gm47?node-id=8-651).
Route: `/v/[ventureId]/command`. All implementation and verification are local.

The exact design context and its rendered screenshot were inspected before editing. The implementation uses the existing Next.js, React and CSS-module stack, semantic tokens, Brand, AccountMenu, and existing task actions. Inter is self-hosted for this screen; Geist Mono is reused. Figma timeline SVGs are local, non-empty, and retain their original 6×6 dimensions.

## Visual comparison

Desktop was rendered at 1440×900 and compared directly with the Figma screenshot. The shell is 220px wide with a 48px top bar; content starts at (252, 80). The two 566px columns have a 24px gap. Each row is 382px tall, with the bottom row starting at y=486. Timeline and task panels occupy the remaining height below their section titles. Six metric cards, five timeline events, two insight cards, five sample task rows and all three priority states reproduce the reference.

The first capture exposed an oversized logo, cumulative metric-card offsets and insight text offsets caused by layout borders. These were fixed using the reference logo dimensions and inset borders. The implementation was captured again after correction. Mobile was inspected as a full-page Pixel 7 capture, with stacked quadrants, wrapping timeline/task copy, and no horizontal overflow. The mobile task-management disclosure was moved below the rows to avoid crowding.

## Deliberate differences

- “Sample data” replaces “Live”; fixture insights say “Sample analysis” rather than implying live AI analysis. The date remains the deterministic reference date.
- The venture name, user name, role and initials avatar use the authenticated identity rather than the design's Sarah Mitchell fixture photo.
- All Portfolio, Build and Operate navigation labels are present. Unshipped destinations are disabled and explain their availability on hover, rather than linking to missing modules.
- The reference clips lower sidebar items and the profile at 900px. The sidebar scrolls so the complete navigation and account profile remain accessible.
- Existing real tasks replace sample task rows when present. Existing task history and task rules replace the corresponding fixtures when available. Creation, completion and reopening use the existing authorised server actions. Demo checkboxes are presentation only.
- A small “Manage venture tasks” disclosure is added to the task panel for roles that can manage tasks. The form stays collapsed in the reference view.
- The app fills the browser viewport; Figma's surrounding white presentation canvas, outer rounded frame and drop shadow are omitted.
- Mobile uses a menu sheet and stacked content because the provided reference is desktop only.

## Validation

TypeScript checking and focused ESLint passed (only Next.js recommendations for the tiny SVG image elements). The unit suite passed 295 tests across 23 files. Desktop/mobile Command Centre browser tests passed, including serious/critical accessibility checks, exact shell dimensions, viewport overflow, creation/completion/reopening, viewer access and outsider denial. Final screenshot verification also checks the sidebar profile and mobile menu.
